## Requirements
### Requirement: 1つの入力ですべてを探す
検索は1つの入力だけで行い、項目ごとの絞り込み UI を持ってはならない（SHALL NOT）。入力が空のときは全レシピを表示する。

#### Scenario: 入力する前
- **WHEN** 画面を開いて何も入力していない
- **THEN** 全レシピが料理名順に並んで表示される

#### Scenario: 入力すると絞り込まれる
- **WHEN** 入力欄に語を打つ
- **THEN** 一致するレシピだけが表示される

#### Scenario: 入力欄に自動でフォーカスしない
- **WHEN** 画面を開く
- **THEN** 入力欄にフォーカスは当たらず、一覧がすぐ見える状態になる

#### Scenario: 入力を消すと全件に戻る
- **WHEN** 入力欄を空にする
- **THEN** 全レシピが料理名順に並んだ状態に戻る

### Requirement: 表記の違いを越えて一致する
検索は、ひらがなとカタカナの違い、全角と半角の違い、英字の大文字と小文字の違いを区別してはならない（SHALL NOT）。加えて、レシピ側の漢字表記は、その読みでも一致しなければならない（SHALL）。

読みが効くのはレシピ側の表記に対してだけである。入力に打った漢字を読みに読み替えることはしない。

#### Scenario: ひらがなとカタカナ
- **WHEN** 材料がカタカナで書かれたレシピに対し、同じ語をひらがなで打つ
- **THEN** そのレシピは一致する

#### Scenario: 漢字表記をかなで引く
- **WHEN** 材料が漢字で書かれたレシピに対し、その読みをかなで打つ
- **THEN** そのレシピは一致する

#### Scenario: 全角と半角
- **WHEN** 全角の英数字で書かれた語を、半角で打つ
- **THEN** そのレシピは一致する

#### Scenario: 表記そのものでも一致する
- **WHEN** 材料が漢字で書かれたレシピに対し、同じ漢字を打つ
- **THEN** そのレシピは一致する

#### Scenario: 入力側の漢字は読み替えられない
- **WHEN** かな・カナで書かれたレシピに対し、その語の漢字表記を打つ
- **THEN** そのレシピは一致しない（かなで打てば一致する）

### Requirement: 空白区切りはすべてを含む条件
空白で区切られた複数の語は、そのすべてを含むレシピだけに絞り込まなければならない（SHALL）。語ごとに、表記そのものと読みのいずれかで一致すればよい。空白以外の記号を演算子として解釈してはならない（SHALL NOT）。

#### Scenario: 2語で絞り込む
- **WHEN** 空白で区切った2語を打つ
- **THEN** 両方の語を含むレシピだけが表示される

#### Scenario: 語が別々の項目に散っている
- **WHEN** 一方の語が料理名に、もう一方が材料に含まれるレシピがある状態で、その2語を打つ
- **THEN** そのレシピは一致する

#### Scenario: 一方だけ一致する
- **WHEN** 片方の語だけを含むレシピがある状態で、2語を打つ
- **THEN** そのレシピは一致しない

#### Scenario: 記号は演算子にならない
- **WHEN** 縦棒や感嘆符などの記号を含む語を打つ
- **THEN** 記号は語の一部としてそのまま扱われる

### Requirement: 検索の対象
検索は、料理名・材料・自動調理キー・自動メニュー番号・手動設定・手順・レシピの ID を対象にしなければならない（SHALL）。

#### Scenario: 自動メニュー番号で引く
- **WHEN** 自動メニュー番号を打つ
- **THEN** その番号を持つレシピが一致する

#### Scenario: ID をローマ字で引く
- **WHEN** レシピの ID の一部をローマ字で打つ
- **THEN** そのレシピが一致する

#### Scenario: 手順の言葉で引く
- **WHEN** 手順の中にだけ現れる語を打つ
- **THEN** そのレシピが一致する

### Requirement: 並びは料理名順のまま
絞り込んだあとも、表示は料理名順でなければならない（SHALL）。一致の度合いで並べ替えてはならない（SHALL NOT）。同じ入力からは常に同じ並びが得られる。

#### Scenario: 絞り込んでも並びが変わらない
- **WHEN** 複数のレシピが一致する語を打つ
- **THEN** 一致したレシピは料理名順に並ぶ

### Requirement: 日本語入力の変換中は結果を更新しない
日本語入力の変換が確定するまで、検索結果を更新してはならない（SHALL NOT）。未確定の文字で結果が入れ替わると、目的のレシピを探しているあいだ画面が落ち着かないため。

#### Scenario: 変換の途中
- **WHEN** 日本語入力で変換中の文字が入力欄にある
- **THEN** 検索結果は更新されない

#### Scenario: 変換を確定する
- **WHEN** 変換を確定する
- **THEN** 確定した語で検索結果が更新される

### Requirement: 検索語を URL に反映する
検索を実行したとき、検索語を URL に反映しなければならない（SHALL）。このとき履歴を増やしてはならない（SHALL NOT）。検索語を含む URL で開いたときは、その語で絞り込んだ状態から始める。

#### Scenario: 検索語が URL に載る
- **WHEN** 入力欄に語を打って検索が実行される
- **THEN** その語が URL に反映される

#### Scenario: 履歴が増えない
- **WHEN** 検索語を何度も打ち替える
- **THEN** ブラウザの履歴は増えず、「戻る」で1つ前の検索語には戻らない

#### Scenario: 検索語を含む URL で開く
- **WHEN** 検索語を含む URL で画面を開く
- **THEN** 入力欄にその語が入り、絞り込まれた状態で表示される

#### Scenario: 再読み込みしても検索状態が戻る
- **WHEN** 検索したあとに画面を再読み込みする
- **THEN** 同じ検索語で絞り込まれた状態に戻る

### Requirement: 一致するレシピが無いとき
一致するレシピが1件も無い場合、一致が無いことと、打った検索語を示さなければならない（SHALL）。入力を消して全件に戻る手段を用意する。

#### Scenario: 一致0件
- **WHEN** どのレシピにも一致しない語を打つ
- **THEN** 一致するレシピが無いことと打った検索語が示され、入力を消して全件に戻せる

### Requirement: レシピを読み込めないときは知らせる
検索インデックスを取得できない場合、その旨を表示しなければならない（SHALL）。レシピが0件であるかのように見せてはならない（SHALL NOT）。原因の分からない空の画面にしないため。

#### Scenario: 読み込みに失敗する
- **WHEN** 検索インデックスを取得できない状態で画面を開く
- **THEN** レシピを読み込めなかった旨が表示され、一致0件の表示とは区別できる

#### Scenario: 検索できないことが分かる
- **WHEN** 読み込みに失敗した状態で入力欄に語を打つ
- **THEN** 検索結果は出ず、読み込めていないことが引き続き示される
