## Requirements
### Requirement: 詳細は一覧に重ねたダイアログで表示する
レシピの詳細は、一覧の上に重ねたダイアログとして表示しなければならない（SHALL）。ダイアログを開いているあいだ、背後の一覧と入力欄は操作できない。内容は 料理名 → 調理方法 → 材料 → 手順 の順に並べる。

#### Scenario: 一覧から開く
- **WHEN** 一覧のレシピを選ぶ
- **THEN** そのレシピの詳細がダイアログで表示される

#### Scenario: 表示の順序
- **WHEN** 全項目が埋まったレシピの詳細を開く
- **THEN** 料理名・調理方法・材料・手順がこの順に表示される

#### Scenario: 手順が無いレシピ
- **WHEN** 手順の書かれていないレシピの詳細を開く
- **THEN** 料理名・調理方法・材料が表示され、手順は空として扱われる

### Requirement: 調理方法は値のあるものだけをまとめて表示する
自動調理キーと自動メニュー番号は同じ調理方法を指すため、値のあるものを1つの表示にまとめなければならない（SHALL）。値の無い項目は表示しない。自動調理キー・自動メニュー番号・手動設定のいずれにも値が無い場合、調理方法の区画そのものを表示してはならない（SHALL NOT）。

#### Scenario: 自動調理キーと自動メニュー番号の両方がある
- **WHEN** 自動調理キーと自動メニュー番号の両方に値があるレシピの詳細を開く
- **THEN** 両方が1つの調理方法としてまとめて表示される

#### Scenario: 自動メニュー番号だけがある
- **WHEN** 自動メニュー番号だけに値があるレシピの詳細を開く
- **THEN** 番号だけが調理方法として表示され、自動調理キーの表示は現れない

#### Scenario: 自動調理キーだけがある
- **WHEN** 自動調理キーだけに値があるレシピの詳細を開く
- **THEN** 自動調理キーだけが調理方法として表示される

#### Scenario: 自動調理キーと手動設定の両方がある
- **WHEN** 自動調理キーと手動設定の両方に値があるレシピの詳細を開く
- **THEN** 両方とも表示される（どちらか一方に絞らない）

#### Scenario: 調理方法が何も無い
- **WHEN** 自動調理キー・自動メニュー番号・手動設定のいずれにも値が無いレシピの詳細を開く
- **THEN** 調理方法の区画そのものが表示されず、料理名の次に材料が並ぶ

### Requirement: URL がダイアログの開閉を唯一に決める
URL のうち `#` に続く部分に置かれたレシピの ID が、どのレシピの詳細を開いているかを唯一に決めなければならない（SHALL）。ダイアログの開閉を URL と独立に切り替えてはならない（SHALL NOT）。開閉の起点を1つに保ち、ブラウザの操作と表示がずれないようにするため。

#### Scenario: 一覧から選ぶと URL が変わる
- **WHEN** 一覧のレシピを選ぶ
- **THEN** URL の `#` に続く部分がそのレシピの ID になり、詳細が開く

#### Scenario: ID が取り除かれると閉じる
- **WHEN** URL の `#` に続く部分からレシピの ID が取り除かれる
- **THEN** ダイアログは閉じ、一覧が操作できる状態に戻る

#### Scenario: レシピの ID を含む URL で開く
- **WHEN** レシピの ID を含む URL で画面を開く
- **THEN** そのレシピの詳細が開いた状態で表示される

### Requirement: 閉じる操作と戻る操作
ダイアログは、Esc キー・閉じるボタン・ダイアログの外側を選ぶ操作・ブラウザの「戻る」のいずれでも閉じられなければならない（SHALL）。閉じたあとは一覧に戻り、そのときの検索語は保たれる。

#### Scenario: それぞれの操作で閉じる
- **WHEN** 詳細を開いた状態で、Esc キー・閉じるボタン・ダイアログの外側・ブラウザの「戻る」のいずれかを行う
- **THEN** ダイアログは閉じ、一覧が表示される

#### Scenario: 閉じても検索語が残る
- **WHEN** 検索して絞り込んだ状態から詳細を開き、閉じる
- **THEN** 絞り込まれた一覧に戻り、検索語は入力欄に残っている

#### Scenario: 直接開いた詳細を閉じる
- **WHEN** レシピの ID を含む URL で開いた詳細を閉じる
- **THEN** ダイアログは閉じて一覧が表示され、画面の外へ出てしまわない

### Requirement: どのレシピにも一致しない ID は詳細を開かない
URL の `#` に続く部分がどのレシピの ID にも一致しない場合、詳細を開いてはならない（SHALL NOT）。一覧を表示する。

#### Scenario: 一致しない ID を含む URL で開く
- **WHEN** どのレシピの ID にも一致しない値を `#` に続けた URL で画面を開く
- **THEN** ダイアログは開かず、一覧が表示される
